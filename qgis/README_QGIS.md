# EquiPop for QGIS — installing it

EquiPop is a Python package that does the calculating, plus a small
plugin that puts two tools in QGIS's Processing toolbox. Both halves
have to be present, and the awkward part is that **the package must
be installed into the Python that QGIS itself uses**, which is
usually not the Python you get by typing `python` in a normal
command prompt.

That is the whole difficulty. Everything else is copying a folder.

---

## Step 1 — install the package into QGIS's Python

**Windows (OSGeo4W / the standalone installer)**

Open the **OSGeo4W Shell** from the Start menu — not an ordinary
Command Prompt — and run:

```
python -m pip install --upgrade equipop
```

**macOS and Linux**

Use the Python that QGIS was built against. From inside QGIS, the
surest way is the **Python Console** (Plugins ▸ Python Console):

```python
import subprocess, sys
subprocess.run([sys.executable, "-m", "pip", "install", "--upgrade",
                "equipop"])
```

`sys.executable` inside QGIS *is* QGIS's Python, so this cannot
install into the wrong place.

**Check it worked** — in the QGIS Python Console:

```python
import equipop; print(equipop.__version__)
```

A version number means you are done with the hard part. A
`ModuleNotFoundError` means it went into a different Python; use the
Python Console method above.

---

## Step 2 — install the plugin

Copy the folder `equipop_qgis` into your QGIS plugins directory:

| System | Location |
|---|---|
| Windows | `%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\` |
| macOS | `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins/` |
| Linux | `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/` |

Then restart QGIS and enable **EquiPop** under Plugins ▸ Manage and
Install Plugins ▸ Installed.

The tools appear in the Processing Toolbox under **EquiPop**:

- 1. Counts and Shares (k / radius)
- 2. Value Statistics (k / radius)

---

## If a tool refuses

The plugin tries to say what to do rather than only what went wrong.

**"The EquiPop Python package is not installed in the Python that
QGIS uses"** — step 1 went into the wrong Python. Use the Python
Console method.

**"…has no equipop.doors module"** — the package is there but older
than the plugin. Run the upgrade line again in the right Python and
restart QGIS.

**"The target is a SHAPEFILE and shapefile field names are capped at
10 characters"** — shapefiles cannot hold names like
`Mean_income_1600`. Write to a **GeoPackage (.gpkg)** instead; it has
no such limit. This is the same rule ArcGIS users meet, where a file
geodatabase plays the part a GeoPackage plays here.

---

## Does it give the same answers as the ArcGIS version?

Yes, and this is tested rather than asserted. Both doors are run over
the same synthetic town (Gridby) and compared against a reference
table generated by the Python core, column by column: counts must
match exactly, continuous values within a tight tolerance. A door is
not considered finished until it passes.

To see it for yourself:

```python
from equipop.doors.reference import load_reference, compare, explain
print(explain(compare(your_result_table)))
```

## What is not here yet

*(Corrected in 1.29.5, BACKLOG 121. This section had said that decay,
barriers, terrain and the grouping table were absent from QGIS. Three
of those four arrived releases ago, and the paragraph had been telling
users to open ArcGIS for things sitting in front of them.)*

**Present in QGIS:** distance decay with a fixed half-life; barriers
as vector layers, as a GeoPackage layer, and as friction rasters;
terrain and slope; the category grouping table on both ladders; and
self-potential.

**Genuinely still missing (BACKLOG 102):** the VARIABLE-BANDWIDTH
controls. ArcGIS offers a half-life taken from a field, a
self-calibrating half-life set by each point's own `Dist_k`, and a bin
count. QGIS offers only the fixed half-life. That is the headline
feature of 1.17 and it has never been reachable from this door. The
shared code is underneath, so it is a matter of adding the boxes.
